# Midterm Submission Package

## 1. Source Code
- Python scripts are available in the project under `scripts/`.
- Core execution scripts:
  - `scripts/preprocess_patient.py`
  - `scripts/run_patient.py`
  - `scripts/compare_models.py`
  - `scripts/math_report.py`
  - `scripts/plot_results.py`

## 2. Dataset + preprocessing record
- Processed dataset archive and summary are stored under `data/processed/chb01/`.
- CSV export generated by:
  - `scripts/export_midterm_dataset.py`
- Output file:
  - `data/processed/chb01/chb01_preprocessed_summary.csv`

The CSV summarizes each processed record with:
- patient and record ID
- number of windows
- ictal/interictal counts
- seizure duration and count
- retained channels
- preprocessing method used

## 3. Abstract
- Abstract file: `reports/midterm_abstract.md`

## Notes
The repository already contains the main project code and generated benchmark/figure outputs. The missing submission elements were the processed dataset CSV and the project abstract, which are now included for midterm submission.
